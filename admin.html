Cómo publicar los cambios

  1. Abre este administrador localmente en tu computadora.
  2. Importa el JSON vigente o crea un nuevo inmueble.
  3. Selecciona un inmueble y realiza los cambios necesarios.
  4. Agrega las fotografías y sus títulos.
  5. Copia los archivos de imagen a la carpeta img/casas/.
  6. Guarda cada inmueble para regresar al inventario actualizado.
  7. Al terminar, descarga casas.json.
  8. Reemplaza data/casas.json en tu repositorio GitHub.
  9. Sube también las fotografías nuevas y espera la actualización de GitHub Pages.

Importante: el administrador registra las rutas de las imágenes, pero no las sube automáticamente a GitHub. Debes colocar los archivos en img/casas/ y subirlos al repositorio.
