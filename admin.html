Administración de casas

Edita el catálogo en tu computadora y descarga el JSON actualizado. No se guardan datos en un servidor.

Carga tu archivo casas.json o crea una nueva propiedad.

Propiedades

Editor de propiedad

Espacios de la casa

Registra sala, comedor, cocina, recámaras, baños, jardín u otros. La fotografía es opcional.

Cómo publicar los cambios

  1. Abre este administrador localmente en tu computadora.
  2. Importa el JSON vigente o crea las casas.
  3. Guarda los cambios y descarga casas.json.
  4. Reemplaza data/casas.json en tu repositorio GitHub.
  5. Sube los archivos del sitio y espera la actualización de GitHub Pages.

Fotografías: se guardan dentro del JSON como imágenes optimizadas. Mantén un tamaño razonable y respalda el archivo; muchas imágenes pueden hacerlo pesado.
